# Data-Science-and-Machine-Learning-Web-Application
1,200 historical charging session records in `ev_campus_dataset.csv`; developed an end-to-end Python pipeline using NumPy, Pandas, Matplotlib, Seaborn, Scikit-Learn, and Streamlit to analyze historical grid usage, train a predictive machine learning model, and deploy an interactive web portal for campus facility engineers.
